* Key-value tasks and rewards for custom player progression.
* Player NBT tasks with searchable fields and manual input, including mod data.
* Server-wide task progress with minimum personal contribution requirements.
* Timed challenges with countdowns and optional resets.
* Daily and weekly quest schedules with configurable reset times and rotating quest pools.
* Calendar streak rewards with bonus items.
* Permanent or timed attribute bonuses as rewards.
* Console execution for command rewards.
